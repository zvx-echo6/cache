# Default classes and division descriptions

These are the divisions and their drafted descriptions (Cache Decimal System, CDS; `vault/projects/cache-classification.md`). The folder names come from them, and a division with no description is not in use. Which division a book goes in is decided by the trained classifier (a model file), not by comparing against these descriptions. They are never shown to the assistant. The device copy is `<data>/build/classes.json`; edit it there. Division 060 is unassigned.

- **020 General manuals and guides**: Broad how-to manuals and handbooks that span many practical skills, such as all-purpose self-reliance, homesteading and field manuals.
